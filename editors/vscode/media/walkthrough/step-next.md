# Next Steps

You now know the core features of Asatsuyu. Here's where to go next:

**Explore examples** in the `asatsuyu/examples/` directory:
- `hello.asty` — minimal program
- `ffi_test.asty` — Python FFI basics
- `tutorial_file_inventory.asty` — full 300-line pipeline with ADTs, FFI, and pattern matching

**Editor features** to try:
- **Hover** over any variable to see its type
- **Go to Definition** (F12) to jump to where a name is defined
- **Rename** (F2) to rename a symbol across all references
- Type `fn` or `match` and press Tab to expand a snippet
- Run **Asatsuyu: Open Syntax Guide** from the Command Palette when you need the full grammar reference

**Build and run** your first program:
```bash
asatsuyu run my_file.asty
```
